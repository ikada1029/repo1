## 2. 변경하지 않은 부분

- 4.1 닉네임, 4.2 직업, 5.1 농부, 5.2 광부, 5.5 공통 성장, 7.2~7.4 시장·상점·출석, 8장 게시판·거래, 9.1 토지, 9.4~9.5, 12장 범죄·감사, 13장 추가 소각 콘텐츠는 v0.1 그대로다. (단 9.4 가구 직접 구매 등은 9.3 개정과 정합.)
- 낚시 타이밍 판정(5.4)은 유지한다.

## 3. 미반영·남은 항목

- **UI 구현 방식**(서버 메뉴 vs 커스텀 화면)과 시즌 풀 종료 정책 등은 19장 미확정에 추가했다.
- 6.1의 인터페이스·수치는 모두 제안이며 실측·G3 입력 교체 후 확정한다.
- 이 사본은 **원본(업로드 파일)을 대체하지 않는다.** 원본에 반영하려면 위 목록의 절을 같은 방식으로 옮기면 된다.
