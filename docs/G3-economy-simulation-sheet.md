# G3 — 경제·밸런스 시뮬레이션 시트 구조

> 대상: 명세서 v0.1 7장(경제), 5장(직업), 6.2장(강화), 9.3장(가구 뽑기), 18장(밸런스 측정)
> 형태: 스프레드시트(Excel/Google Sheets) 1개 파일. 아래 시트 순서대로 만든다.
> 원칙: **모든 수치는 `Params` 시트 한 곳에서만 입력**하고, 나머지 시트는 수식으로 참조한다. 명세의 수치는 전부 [제안]이므로 이 시트에서 검증 후 확정한다.

## 3. `JobIncome` — 직업별 시간당 수익

행: 직업 × 레벨 구간(초급 1~15 / 중급 16~35 / 고급 36~50) · 열:

| 열 | 수식(개념) |
|---|---|
| 시간당 생산량 | `Items` 참조 |
| 시간당 총수익 | `Σ 생산량 × P_sell` |
| 시간당 비용 | 씨앗·재료·물뿌리개·탄약 등 |
| **시간당 순수익** | 총수익 − 비용 |
| 직업 간 편차 | `순수익 / 4직업 평균` |

**합격 기준(제안):** 동일 구간에서 직업 간 편차 **0.8~1.25배** 이내. 요리사는 `레시피 판매가 − 원재료비 > 0` 이어야 한다(5.3장).

## 4. `PriceSim` — 변동 시세 시뮬레이션

품목별 · 일 단위(예: 90일) 행으로 전개한다.

| 열 | 수식 |
|---|---|
| `Day` | 1..N |
| `판매량` | `인구 × 판매 비율 × 시간당 생산량 × 플레이 시간` |
| `Q` | `EMA(판매량, ema_days)` |
| `P_raw` | `P_base × (D / MAX(Q, Q_min)) ^ alpha` |
| `P_clamped` | `MIN(MAX(P_raw, P_floor), P_cap)` |
| `P_today` | `전일가 × (1 + clamp(P_clamped/전일가 − 1, −상한, +상한))` |
| 일일 매출 | `판매량 × P_today` (= 신규 발행) |

**확인 포인트:** 가격이 하한에 장기간 붙어 있지 않은지, 한 직업 과잉 시 가격이 수렴하는지, 변동폭 상한이 진동을 만드는지.

## 5. `Enhance` — 강화 기대 비용

단계 `n`(0→1, 1→2 …)별 행:

| 열 | 내용 |
|---|---|
| 성공률 `s` / 실패 유지율 `k` / 파괴율 `d` | 입력, **`s + k + d = 1` 검증열** |
| 1회 비용 | Coin + 강화석 수 |
| 강화석 Coin 환산가 | 광부 시간당 수익 기반 |
| 기대 시도 수 | `1 / s` (파괴 시 재시작 모델은 아래) |
| **파괴 포함 기대 비용** | 아래 수식 |
| 누적 기대 비용 | 단계 합 |

파괴 시 장비를 다시 구매해 해당 단계까지 재도전한다고 가정하면, 단계 `n`의 기대 비용 `E_n`은

```text
E_n = (c + d × R_n) / s        # c: 1회 비용, R_n: 파괴 시 재구축 비용(구매가 + 하위 단계 누적)
```

(성공 시 다음 단계로, 실패 유지 시 같은 단계 반복, 파괴 시 `R_n`만큼 손실 후 재도전.)

**환산 지표:** 목표 단계까지의 `기대 비용 ÷ 중견 유저 일일 순수익 = 필요 일수`.

**합격 기준(제안):** 주요 목표 구간(예: 보스 진입 단계) 도달에 필요한 일수가 G0의 설계 목표와 일치. 파괴율이 높은 구간에서 90% 분위 비용이 평균의 2배를 넘지 않음(몬테카를로 열 추가 권장).

## 6. `Gacha` — 가구 뽑기

| 블록 | 내용 |
|---|---|
| 확률표 | 티어별 확률(합 = 100% 검증), 풀 가구 수 |
| 기본 기대 | 티어별 기대 획득 수 = 뽑기 수 × 확률 |
| 천장(50회 영웅↑) 보정 | 천장 적용 시 **실효 영웅 이상 확률** 계산 → UI 공개 확률과의 차이 문서화 |
| 컬렉션 완성 | 풀 크기 `N`에서 전체 수집 기대 뽑기 수 ≈ `N × H_N`(쿠폰 수집가 근사), 중복 조각 환산 반영 |
| 조각 교환 | 중복 → 조각 수 / 지정 교환 필요 조각 → 최악·평균 비용 |
| 소각 | 뽑기 가격 × 뽑기 수 = **Coin 소각**(유저 간 가구 거래는 이동 — 집계 분리) |
| 시뮬레이션 | 열 N회 난수 시행 → 분포 확인(시트 `RAND()` 또는 별도 스크립트로 결과 붙여넣기) |

**합격 기준:** 시뮬레이션 분포가 공개 확률과 오차 범위 내 일치, 천장 포함 실효 확률 공개 문구 확정, 일반 유저가 "한 달 소득의 X%" 이내로 전설 1개 기대 가능(X는 G0에서 결정).

## 8. `FlowBalance` — 발행/소각/이동

일 단위(또는 유저 유형별) 집계:

| 구분 | 항목 |
|---|---|
| **발행(Faucet)** | NPC 판매액, 퀘스트·업적 보상, 출석, 이벤트 |
| **소각(Sink)** | `Housing_Sinks` 합계 + 강화·인챈트 + 수수료 |
| **이동(Transfer)** | 유저 간 거래·의뢰·경매 (총통화량에 영향 없음, 별도 열) |
| **순증감** | 발행 − 소각 |
| 총통화량 | 전일 + 순증감 |
| 1인당 평균 보유 Coin | 총통화량 / 인구 |

**합격 기준(제안):** 90일 시뮬레이션에서 순증감이 0 이상이면서 1인당 보유량이 일일 소득의 N배(예: 30배)를 넘지 않음. 인플레이션/디플레이션 판정은 18장 원칙(1:1 고정이 아니라 유저 구간별 균형)에 따른다.

## 12. 주의

- 실제 생산량·시간 데이터는 P2 이후 실측으로 교체한다. 초기 값은 **가정**임을 시트에 명시한다.
- 시트는 `rates_version`(6.2장)·`pool_version`(9.3장)과 같은 버전 표기를 유지해, 확정된 수치가 설정 파일과 1:1로 대응되게 한다.
- 확률형 요소의 최종 수치는 운영 검토(G6) 후 확정한다. 이 서버는 현금 과금이 없고 Coin만 사용하므로 별도의 법적 검토 대상은 아니다.

### 13.1 구현 중 얻은 설계 교훈

- **강화 비용을 "일 소득 비중"으로 소각에 반영해야 한다.** 처음에는 `시도 횟수 × 비용`으로 계산했더니 중견 유저 일 소득의 2.6배를 쓰는 비현실적 값이 나왔다. 소각은 소득을 넘을 수 없으므로 `중견 일 소득 × 강화 비중`으로 바꿨다.
- **누락된 소각 경로가 통화량을 폭주시킨다.** 직업 부대비용(씨앗·입장·연료·미끼), 요리 재료비(NPC 구매), 상점 구매를 소각으로 넣지 않으면 발행 대비 소각이 20~50%에 그쳐 90일 뒤 1인당 보유량이 일 발행의 36~60배가 된다. 기본값은 이 항목들을 모두 반영해 24배로 맞췄다.
- **직업 쏠림 시나리오(농부 70%)에서 직업 간 순수익 비율이 0.36~1.39로 무너진다.** 한 직업에 인구가 쏠리면 시세가 하한 방향으로 움직여 설계 목표(0.8~1.25)를 벗어난다. 운영 시 매입 수요와 인구 비율을 모니터링하고 조절해야 한다는 근거다.
- **인구 2배 시나리오에서 요리 마진이 줄고 강화 도달 일수가 19.8일로 늘어난다.** 강화 비용·목표 매입량이 인구에 비례하지 않기 때문이다. 인구가 늘면 수요(D)와 소각 항목도 함께 조정해야 한다.

### 13.2 한계 (후속 과제)

- 난수 시뮬레이션은 **기본 시나리오 입력의 정적 결과**다(MonteCarlo). 입력을 바꾸면 스크립트를 다시 실행해야 한다. 시나리오별 난수 분포와 쿠폰 수집 조각 교환(조각 변환)은 미구현.
- 방어력 상성, 우클릭 특수 공격 DPS, 효과 포함 실측 DPS는 반영하지 않았다.
- 수치는 모두 [제안]이며, **기본값은 기본 시나리오가 합격 기준을 통과하도록 조정한 임시값**이다(직업별 부대비용, 소각 비중 등). 실측 데이터(P2 이후)로 교체해야 한다.

**강화 총비용(장비 구매가 포함)**

**설계 시사점**
- 천장을 영웅 이상에만 두면 전설 꼬리가 길어진다. 전설 별도 천장(예: 150회)이나 "특정 전설 선택 천장"을 도입하면 P90이 크게 낮아진다 — 다음 시뮬레이션 후보.
- 강화 파괴 위험 구간(+10 이후)의 보호 장치 효과를 같은 방식으로 비교할 수 있다(파괴 확률 -X%p, 보호 아이템 등).

- **MonteCarlo 재생성:** 입력(Params, Enhance 확률, 뽑기 확률·풀)을 바꾼 뒤 `python3 -I tools/g3_sheet/build_g3.py` (빠른 확인은 `--quick`). 시행 횟수와 시드는 `run_mc()` 인자.

### 13.5 뽑기 천장 구조 비교 (Gacha_Compare 시트, 시드 20261112, 구조당 2만 회)

**조각 교환 비용 민감도**(현행 천장 + 교환): 200조각 → 평균 137회/P90 171회, 300 → 174/222, 400 → 206/269, 600 → 259/358, 800 → 302/444, 1,200 → 373/607.

**해석**
- **영웅+ 천장은 전설 획득에 거의 영향이 없다**(S0 ≈ S1). 영웅 이상 보장 뽑기에서 전설 비율이 약 10%라 전설 분포를 거의 바꾸지 못한다. 전설 체감은 별도 장치가 필요하다.
- **전설 하드 천장(S2)은 P90을 150회로 묶지만** 평균 비용을 23% 줄인다.
- **소프트 천장은 강하다.** 70회부터 +1.5%p는 평균 소각을 45% 줄여 Coin 싱크가 크게 약해진다. 약하게(90회부터 +0.6%p) 해도 평균 35% 감소한다.
- **지정 전설은 선택 천장·조각 교환이 훨씬 효과적이다.** 평균을 600회에서 200~250회로, P90을 1,380회에서 270~350회로 줄인다. 대신 **지정 전설을 노리는 유저의 평균 소각이 60~65% 감소**한다.
- 조각이 중복에서 빨리 쌓이므로(신규 유저 기준 약 1.7조각/회) **조각 교환 비용이 사실상 '평균 뽑기 수'를 정하는 조절 다이얼**이다. 400조각이면 평균 약 205회다.
- **추천 후보 S7**: 전설 150회 하드 + 지정 선택 450회(안전망) + 조각 600 교환. 전설 첫 획득 P90 150회(월소득의 68%), 지정 전설 평균 246회·P90 353회(월소득의 약 1.6배, 약 21만 Coin), 최악 상한 450회. 현행 대비 평균 비용 0.41배.

**경제 영향과 설계 시사점**
- 천장을 완화하면 **가구 뽑기 소각이 줄어든다**(지정 전설 추구 기준 35~65%). 뽑기 싱크가 전체 소각의 약 3%이므로 영향은 제한적이지만, 소각이 부족해지면 가구 직접 구매·주택 확장 등 다른 싱크를 늘려야 한다(`Housing_Sinks`).
- 판정 기준(전설 첫 획득 P90 ≤ 월소득 100%, 지정 전설 P90 ≤ 300%)은 입력값이므로 운영 목표에 맞게 바꿀 수 있다.
- 미반영: 조각을 이벤트·구매로 얻는 경로, 이미 컬렉션 일부를 가진 유저, 10회 구매 할인, 여러 천장 구조의 심리적 체감(예: 소프트 천장의 구간 체감).

**보호권 민감도(+12, 8단계부터 사용)**: 가격 0 → 평균 46,289(현행 대비 0.75) / 500 → 0.82 / 1,000 → 0.91 / **1,500 → 0.98(손익분기 부근)** / 2,500 → 1.14 / 4,000 → 1.38. 사용 시작 단계는 5 → 1.09(소멸 0%) / 8 → 0.98(9.5%) / 10 → 0.93(24.9%) / 12(사용 안 함) → 1.00(45.8%).

**해석**
- **손실감(장비 소멸 확률)을 실제로 줄이는 장치는 보호권뿐이다.** +12에서 46%→10%, +15에서 77%→10%. 보호권을 쓰는 동안 파괴가 사라지므로 운이 나쁠 때의 부담(P90)도 +12 −19%, +15 −53%로 크게 줄어든다.
- **환급(E2)은 평균 비용만 줄이고 소멸 확률은 그대로**다(+12 −16%, +15 −28%). "잃는 경험"은 남는다.
- **단계 절반 하락(E3)은 효과가 작다**(−5%). 파괴가 드문 구간이 길어서 하락 이벤트가 적게 발생하기 때문이다.
- **안전 구간 확대(E4)와 강화 천장(E5)은 효과가 거의 없다.** 파괴는 고단계에서 대부분 발생해 저단계 보호가 비용을 거의 줄이지 못하고, 8회 연속 유지는 드물어 변동성이 거의 줄지 않는다.
- **보호권은 가격·시작 단계에 민감하다.** 1,500 Coin에서 +12 비용이 현행과 비슷하고(손익분기), +10에서는 **보호권이 오히려 비용을 늘린다**(필요 이상으로 사용). 사용을 10단계 이후로 제한하면 평균 비용은 줄지만 소멸 확률이 25%로 남는다. 가격을 단계별로 차등(고단계일수록 비싼 보호권)하거나 사용 시작 단계를 정책으로 안내해야 한다.
- **추천 조합 E6**: 안전 구간(8단계 미만) + 보호권(10단계부터 1,500) + 환급 30%. +12에서 평균 −10%, P90 −24%, 소멸 확률 46%→17%이고, +15에서는 평균 −39%, P90 −54%다. 판정 기준(P90÷평균 ≤ 2.0 and 소멸 확률 ≤ 30%)을 +12·+15 모두 통과하는 것은 E1·E6뿐이다.

**경제 영향**
- 보호권이 가격만큼 소각을 만들지만 **파괴 재구매 비용이 줄어드는 만큼 총 소각은 감소**한다(+15 기준 −37~39%). 강화 소각은 전체의 약 36%이므로(`Housing_Sinks`) 전체 소각이 최대 약 10~14% 줄 수 있다. 부족한 소각은 보호권 가격 조정(1,500→2,000대), 단계별 보호권 가격 차등, 다른 싱크로 보완한다.
- 미반영: 보호권을 시도마다 쓰는 단순 규칙(실제 유저는 선택적으로 사용), 보호권 구매 경로·재고 제한, 환급 방식(재료/Coin), 도감 업적 유지의 심리적 완충.

### 13.7 가구에 등급을 두지 않는 경우 (2026-11-11 방침)

가구에 희귀도(일반/희귀/영웅/전설)를 두지 않기로 했으므로 **13.5의 등급 천장 비교는 참고용**이다(`Gacha`·`Gacha_Compare` 1~4절의 확률표는 등급을 가정). 등급 없는 균등 풀 분석은 `Gacha_Compare` 5절(분석식)에 넣었다.

| 풀 크기 N | 지정 1종 평균 | P90 | P99 | 전체 수집 기대 | P90 비용÷중견 월소득 |
|---|---|---|---|---|---|
| 30 | 30회 | 68 | 136 | 120 | 31% |
| 50 | 50 | 114 | 228 | 225 | 51% |
| 68 | 68 | 155 | 311 | 327 | 70% |
| 100 | 100 | 229 | 458 | 519 | 103% |
| 150 | 150 | 344 | 688 | 839 | 155% |

- 등급이 없으면 **모든 가구의 획득 확률이 1/N**이고, 지정 1종은 기하분포(평균 N회, P90 약 2.3N)다. **풀 크기와 1회 가격이 곧 난이도**다.
- 등급 천장(영웅+·전설 하드/소프트)은 의미가 없다. 남는 완화 장치는 **선택 천장(K회 후 지정 가구 보장)** 과 **중복 → 조각 교환**이다. 균등 풀에서는 선택 천장을 2N회로 두면 평균이 약 13% 줄고 최악이 2N으로 묶인다.
- 희귀도를 쓰지 않더라도 **"시즌 한정/상시"처럼 획득 경로 기준 구분**이나 **풀별 가격**으로 가치를 나눌 수 있다. 확률표는 "각 가구 1/N"으로 단순화하고 UI(W-61)도 등급 대신 풀 구성·천장 카운트·조각 보유량 중심으로 바꾼다.
- 가구 직접 구매 가격(뽑기와 별개)이 곧 "획득 비용 상한"이 되므로, 뽑기 기대 비용(평균 N×1회 가격)과의 비율을 설계 지표로 둔다.

### 13.8 등급 없는 균등 풀 가구 뽑기 시뮬레이션 (Gacha_Flat 시트, 시드 20261114)

13.7의 분석식을 난수 시뮬레이션으로 확장했다. 풀 N=68종(기본), 모든 가구가 1/N 확률, 1회 600 Coin, 중견 월소득 약 13.3만 Coin, 신규 유저 기준. **선택 천장 K** = 누적 K회째 지정 가구 보장, **조각** = 중복 1개당 1조각·X조각이 모이면 지정 가구 교환.

**지정 가구 1종 획득까지 (구조당 2만 회)**

| 구조 | 평균 | P50 | P90 | P99 | 상한 | 평균 비용 | F0 대비 | P90 비용÷월소득 |
|---|---|---|---|---|---|---|---|---|
| F0 균등·천장 없음 | 67.6 | 48 | 154 | 300 | 없음 | 40,550 | 1.00 | 69% |
| F1 선택 천장 2N(136) | 58.6 | 47 | 136 | 136 | 136 | 35,152 | 0.87 | 61% |
| F2 선택 천장 1.5N(102) | 52.9 | 47 | 102 | 102 | 102 | 31,741 | 0.78 | 46% |
| F3 조각 X=N(68) | 56.9 | 47 | 124 | 129 | 없음 | 34,168 | 0.84 | 56% |
| F4 조각 X=1.5N(102) | 61.6 | 47 | 154 | 166 | 없음 | 36,960 | 0.91 | 69% |
| F5 선택 2N + 조각 1.5N | 59.2 | 47 | 136 | 136 | 136 | 35,494 | 0.88 | 61% |
| F6 선택 3N + 조각 2N | 63.8 | 46 | 156 | 201 | 204 | 38,251 | 0.94 | 70% |
| **F7 선택 1.5N(102) + 조각 0.5N(34)** | **47.9** | 48 | **83** | 88 | 102 | 28,725 | **0.71** | **37%** |

**조각 교환 비용 민감도(선택 천장 없음)**: X=17(0.25N) → 평균 37 / P90 57, 34(0.5N) → 48 / 83, 51(0.75N) → 53 / 104, 68(N) → 57 / 124, 102(1.5N) → 62 / 153.

**전체 컬렉션(68종) 완성**: 교환 없음 평균 325회·P90 430회, 조각 X=68 → 평균 259회·P90 327회(−20%/−24%), X=102 → 275/355, X=136 → 284/338.

**풀 크기 민감도(F0 vs F7)**: N=30 → 평균 30→21 / P90 67→37, N=50 → 50→35 / 116→61, N=68 → 67→48 / 153→83, N=100 → 101→70 / 231→121, N=150 → 153→106 / 349→182. F7은 모든 풀 크기에서 평균 비용을 약 30% 줄이고 P90을 약 45~48% 줄인다.

**해석**
- 균등 풀의 지정 가구는 기하분포라 **평균이 N, P90이 약 2.3N**이다. 선택 천장 K는 P90과 최악을 K로 묶는다(1.5N이면 P90 102회).
- **조각은 교환 비용이 낮아야 효과가 있다.** 중복 1조각 기준으로는 X=N(68조각)에서 −16%, X=0.5N(34조각)에서 −30%, X=0.25N(17조각)에서 −45%이다. 조각은 중복에서만 쌓이므로 초반에는 거의 모이지 않고(뽑기 수 약 N 이후부터 중복이 늘어난다), 교환 비용을 낮추면 P50은 그대로인 채 **P90만 크게 줄어든다**(꼬리 제거).
- **추천 후보 F7**: 선택 천장 1.5N + 조각 0.5N. 평균 48회(F0 대비 −29%), P90 83회, 최악 102회로 묶이고, 지정 가구 P90 비용이 월소득의 37%다. 판정 기준(P90 비용 ≤ 월소득 50%)을 통과하는 구조는 F2와 F7이다.
- **전체 컬렉션**에서는 조각 효과가 더 크다(평균 −20%). 수집가 유저의 부담을 줄이는 수단이고, 완성에 약 260~325회(15.6~19.5만 Coin)가 든다.
- **1회 가격은 목표 평균 비용에서 역산**한다(5절). 예: 지정 가구 평균 비용을 월소득의 20%로 잡으면 F0는 390 Coin, F7은 560 Coin이며, F7은 가격을 올려도 최악의 부담(P90 35%)이 F0(45%)보다 낮다. **현재 1회 600 Coin은 F0 기준 약 31%, F7 기준 약 21% 수준**이다.
- **경제 영향**: F7은 지정 가구를 노리는 유저의 평균 소각을 약 29% 줄인다. 같은 소각을 유지하려면 가격을 약 40% 올리거나(560→830 등) 풀 크기를 키운다(N=100이면 평균 비용이 약 1.5배).
- 미반영: 조각을 이벤트·구매로 얻는 경로, 이미 컬렉션 일부를 가진 유저, 시즌 한정 가구와 상시 가구의 분리, 10회 구매 할인(5절에서 10% 가정으로 환산만 표시).
