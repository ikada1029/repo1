## 1. 직업 (W-70 ~ W-75)

### W-70 직업 허브 (메인 메뉴 > 직업)

```text
 ┌─────────────────────────────────────────────────────────
 │ 직업                                                   [직업 변경]
 │  ▶ 농부  Lv.12  ▓▓▓▓▓░░░  1,240 / 2,000 XP          활성
 │    광부  Lv.1 (보존)       요리사 Lv.- (미선택)      어부 Lv.- (미선택)
 ├─────────────────────────────────────────────────────────
 │  해금 표                                  다음 해금
 │   Lv.10 ✓ 개인 경작지 구매               Lv.15 🔒 낫 진화 / 공동 경작지
 │   Lv.12 ✓ 스프링클러
 │
 │  직업 도구   [괭이 ★3]  → 진화 가능(Lv.15 필요)
 │  오늘 수익   ◈ 3,420 (시간당 ◈ 1,710)      [상점 이동] [직업 화면 열기]
 └─────────────────────────────────────────────────────────
```

- 직업별 레벨·XP는 개별 저장(명세 4.2장). 비활성 직업은 보존 표시. 활성 직업만 `직업 화면 열기`로 직업별 UI(W-71~74)로 이동.
- 직업은 전투를 막지 않는다는 안내 문구(1.3장 원칙)를 도움말줄에 표시.

### W-71 농부 — 경작지·스프링클러·낫

```text
 ┌─────────────────────────────────────────────────────────
 │ 농부   [경작지] [도구 진화] [수확물 판매] [절도 기록]
 ├──────────────────────────────┬──────────────────────────
 │ 내 경작지 #F-03 (개인)        │  물뿌리개  ▓▓▓▓░░  62%  (62/100)
 │  [경작지 미니맵 8×8]          │  [충전하러 가기]
 │  ░░▓▓▓▓░░  작물 상태         │
 │  스프링클러 2대 (5×5 범위)    │  스프링클러
 │   #1 급수 중  #2 물 부족 ⚠   │   #2 → 물뿌리개로 충전하세요
 │                              │
 │ 공용 경작지 이용 안내         │  오늘 수확 ◈ 2,100  요리사 납품 가능 3
 │  · 점유 중인 밭은 수확 금지   │
 │  · 위반 시 기록(수배 후보)    │  [경작지 확장 ◈8,000]
 └──────────────────────────────┴──────────────────────────
```

- **스프링클러는 정확히 5×5**, 물뿌리개로만 충전, 청크 언로드 시 정지, 오프라인 누적 지급 없음(명세 5.1장)을 문구로 고지.
- 공용 경작지: 점유·예약 표시, 타인 점유 작물 수확 시 **사건 기록 경고**(자동 제재 아님).
- **도구 진화 탭:** 괭이 `나무→돌→철→금→다이아→네더라이트→낫` 단계 막대, 현재 단계 확률·재료·Coin, 낫 해금 조건(Lv.15). 강화창(W-20)과 같은 레이아웃이지만 **직업 도구 전용**(전투 강화와 분리, 도감 제외).
- **절도 기록 탭:** 내가 연루된 `CROP_HARVEST_UNAUTHORIZED` 기록과 처리 상태(W-116으로 연결).

### W-72 광부 — 광산 입장·곡괭이

```text
 ┌─────────────────────────────────────────────────────────
 │ 광부   [광산 입장] [도구 진화] [광물 판매]
 ├─────────────────────────────────────────────────────────
 │  ┌일반 광산┐ ┌심층 광산┐ ┌희귀 광산┐ ┌최상급 광산┐
 │  │ 입장 가능│ │ Lv.20🔒 │ │ Lv.35🔒 │ │ Lv.50🔒   │
 │  │ 인원 8/30│ │         │ │         │ │           │
 │  │ 리셋 02:14:10│       │         │ │           │
 │  └─────────┘ └────────┘ └────────┘ └───────────┘
 │
 │  선택: 일반 광산     입장 조건 ✓ 곡괭이 ★1   [ 입장 ]
 │  채굴 가능 광물: 석탄 · 구리 · 철   (곡괭이 단계에 따라 확장)
 │  강화석 드롭: 낮은 확률(광산 티어·광부 레벨 영향)

```

- 광산 티어 4단계(일반/심층/희귀/최상급, 명세 5.2장), 입장 조건·현재 인원·**리셋 타이머**·채굴 가능 광물 표시. 곡괭이 단계 진화는 W-71 도구 진화 탭과 동일 패턴.
- 입장 시 별도 월드/구역으로 이동(`워프` 확인 팝업). 재생 주기와 보상 중복 방지는 서버 처리.

### W-73 요리사 — 조리 (쿨타임·품질 B안)

```text
 ┌─────────────────────────────────────────────────────────
 │ 요리사   [조리] [납품 의뢰] [레시피 도감]            쿨타임 ░░░░░ 12초
 ├──────────────────────────────┬──────────────────────────
 │ 레시피 (Lv.8 해금)            │  구운 생선 정식
 │ ▶ 구운 생선 정식   ✓ 재료 있음 │  [음식 모델]
 │   채소 스튜        ✓           │  재료  생선 ×2  ✓   소금 ×1  ✓
 │   훈제 고기        재료 부족   │  조리 시간 20초   쿨타임 30초
 │   황금 파이        Lv.15🔒     │  품질  좋음 (Lv.8, 프라이팬 ★2)
 │                              │  판매가 ◈ 140 (품질 보정 ×1.2)
 │                              │  [ 조리 시작 ]
 ├──────────────────────────────┴──────────────────────────
 │ 진행 중: 구운 생선 정식  ▓▓▓▓░░░  14/20초          [ 수령 ]
 └─────────────────────────────────────────────────────────
```

- **판정(Perfect/Good/Fail) 없음**(D-001). 조리 시간 + **플레이어 단위 쿨타임**(D-003) + **품질은 레벨·도구 티어의 결정적 보정**(D-004)을 표시. 쿨타임 중에는 `조리 시작` 비활성 + 남은 시간.
- 재료 차감은 **시작 시 1회**(서버 `CookJob`), 수령 시 지급 1회. 인벤토리 가득이면 보관함. 큐 상한/동시 작업 수는 설정 표시.
- 모드 A(서드파티 블록 직접 사용, `server-core-mod-spec.md` 3.5)를 쓰는 경우 이 화면은 **조회·쿨타임 표시 전용**으로 줄어들고 조리는 블록에서 진행한다. 두 방식에 모두 대응하도록 `조리 시작` 영역을 교체 가능한 컴포넌트로 둔다.
- 납품 의뢰 탭은 게시판(W-50)의 납품 의뢰 필터와 연결.

**낚시 미니게임 HUD** (낚시 중 화면 하단):

```text
 │                  ＋
 │          [ 입질! ]   ▓▓▓░░░  우클릭 (0.6초 안에)
 │   (대체 입력: Space)  (소리 알림 on)
```

- 낚시 미니게임은 서버 판정 시간창 방식을 유지(명세 5.4장). **접근성:** 시각 + 소리 + 진동/화면 테두리 신호, 시간창 길이 완화 옵션, 대체 입력 키, 자동 클릭 방지는 서버 판정.
- 어종 도감은 직업 도감(장비 도감과 별개). 희귀어 공급 계수·수요 표시(시세 연동).

## 2. 공통 (W-80 ~ W-88)

### W-80 출석 보상

```text
 ┌─────────────────────────────────────────────────────────
 │ 출석 보상   오늘 30분 체크  ▓▓▓░  3/4     (총 2시간 주기)
 │  [1회 ✓] [2회 ✓] [3회 ▶ 15분 후] [4회 🔒]     오늘 지급 상한 ◈ 400
 │  보상 ◈ 100 / 회        연속 출석 5일 🎁 보너스 [받기]
 │  · 자리비움(AFK) 시 진행이 멈춥니다
 └─────────────────────────────────────────────────────────
```

- 명세 7.4장(30분×4회, 총 2시간, 소액·일일 상한·리셋·AFK 방지). 받기는 서버 1회 지급.

### W-82 보관함 (우편/지급 대기)

```text
 ┌─────────────────────────────────────────────────────────
 │ 보관함   [전체] [아이템] [Coin] [가구]            12 / 50
 ├─────────────────────────────────────────────────────────
 │  [아이콘] 오크 의자 (뽑기 결과)      인벤토리 가득 → 보관   [받기]
 │  [아이콘] 구운 생선 ×6 (조리 수령)   —                       [받기]
 │  [아이콘] ◈ 1,500 (의뢰 보수)        3일 후 만료             [받기]
 │  [아이콘] 이사 보관: 가구 30개       유예 기한 14일          [배치/회수]
 │                                                 [ 모두 받기 ]
 └─────────────────────────────────────────────────────────
```

- `outbox`·인벤토리 가득·주택 만료·이사 보관 등 **지급 실패 시 항상 여기로** 온다. 만료 임박은 색+아이콘+남은 시간 병기. `받기`는 서버 1회 지급.
- 보관함 용량 확장(Coin 소각)은 상단 `확장` 버튼.

- [ ] 판매 화면의 확정 가격·한도·변동폭 상한이 서버 규칙과 일치한다.
- [ ] 총기 상점이 귀속·거래 금지·강화 제외를 명시하고 오탐 탄약을 노출하지 않는다.
- [ ] 보스 입장 조건(장비 점수·쿨타임·주간 한도)이 서버 값이고 기여도·보상이 1회 지급된다.
- [ ] 수배와 제재가 분리 표시되고 이의 신청이 가능하다.
- [ ] 관리자 모든 변경이 사유 입력과 `admin_audit` 기록을 거친다.
- [ ] 위 화면 모두에서 키보드 조작·색 비의존·번역 키·재접속 복원이 유지된다.
