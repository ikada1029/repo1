# G1 — 모드 기술 타당성 검증 체크리스트

> 대상: Minecraft 1.21.1 + NeoForge 경제·장비강화 서버 (명세서 v0.1, 2.2~2.3장 기준)
> 목적: 개발 착수 전에 "모드가 배포됨"이 아니라 "**우리 조합에서 요구대로 동작함**"을 확인한다.
> 결과물: ① 모드 locklist ② 모드별 판정표(통과/조건부/탈락) ③ 탈락 시 대체안 ④ 위험 등록부 갱신

---

## 0. 진행 방식

- **판정 기호:** ✅ 통과 / ⚠️ 조건부(우회·설정 필요, 내용 기록) / ❌ 탈락 / ⬜ 미실시
- 각 항목에 **날짜·검증자·모드 버전·증거(로그/스크린샷)** 를 남긴다.
- 모드는 **리스크 높은 순서**로 검증한다: `TaCZ → LR → 가구 → Farmer's Delight → Aquaculture 2 → Cataclysm → 기타`.
- 한 모드라도 탈락하면 즉시 중단하지 말고 판정만 기록한 뒤 나머지를 계속한다(대체안 비교에 필요).
- 검증 환경은 항상 **전용 서버 1대 + 클라이언트 2대**(서로 다른 계정)로 한다. 싱글/LAN 결과는 증거로 인정하지 않는다.

## 1. 테스트 환경 준비

- [ ] Java 21 설치 확인 (`java -version`)
- [ ] NeoForge 1.21.1 서버 설치, 빈 모드 상태로 기동 확인
- [ ] 클라이언트 2대에 동일 모드팩 설치 (런처 프로필 동일)
- [ ] JVM 인자·메모리 기록 (예: `-Xms/-Xmx`), 서버 하드웨어 기록
- [ ] 테스트 전용 월드 시드 고정, 월드 백업 스크립트 준비
- [ ] 관리자(OP) 계정 1 + 일반 계정 1 준비
- [ ] 로그 수집 위치 지정 (`latest.log`, `crash-reports/`, 클라이언트 로그)

### 4.4 요리 모드 — Farmer's Delight / Kaleidoscope Cookery — 🟠

> 변경 사항: 요리 **타이밍 판정은 폐지**됐고 조리는 *조리 시간 + 플레이어 단위 쿨타임*으로 제어한다(`server-core-mod-spec.md` D-001·D-003·D-005). 제작 우회·복제 방지는 코어 모드가 담당하므로, 이 절은 "코어가 제어할 수 있는가"를 판정한다.

**공통**
- [ ] 식재료·요리 아이템 ID 목록
- [ ] 음식 효과(포만감·버프)를 서버 설정으로 제한 가능한지
- [ ] 조리 블록(솥·웍·냄비·도마·화로)의 우회 제작 경로 확인
- [ ] 레시피가 데이터팩 JSON인지 런타임 생성인지 (코어 레시피 필터 대상 확인)

**조합 비교 (A/B/C)**
- [ ] A: Farmer's Delight 단독
- [ ] B: Kaleidoscope Cookery 단독
- [ ] C: 병행 (Kaledelights Compat 사용 여부 포함 — **1.21.1 NeoForge 빌드 존재 여부를 파일 목록에서 확인**)
- [ ] C 선택 시 동기화 레시피가 코어 필터로 모두 제거·통제되는지

**코어 제어 방식 판정 (D-005)**
- [ ] 코어가 조리 시작/완료를 통제하면서 서드파티 블록의 **모션·애니메이션·모델·소리**를 그대로 재사용할 수 있는가?
  - [ ] 서드파티 자체 조리 진행을 무시·비활성화할 수 있는가
  - [ ] 블록 상태/연출을 코어가 트리거(진행 중·완료 표시)할 수 있는가
  - [ ] 클라이언트 연출이 서버 판정과 어긋나지 않는가
- [ ] **가능 → 모드 B(코어 제어)**, **불가 → 모드 A(서드파티 방식 + 최소 방어층)**

**모드 A 선택 시 추가 검증**
- [ ] 결과 수령 시점에 코어가 직업·레벨·플레이어 쿨타임을 검증할 수 있는가
- [ ] 수령 아이템에 품질 컴포넌트를 부여할 수 있는가
- [ ] 호퍼/자동화로 조리 블록에 재료를 넣는 우회 차단
- [ ] 재료 1회 소비 확인(창 닫기·재접속·크래시)
- [ ] Create Automation 애드온 등 자동화 애드온 제외 확인

**쿨타임 (플레이어 단위)**
- [ ] 플레이어별 `cooldown_until`이 재접속·서버 재시작 후에도 유지되는가
- [ ] 여러 조리 블록을 동시에 써도 쿨타임이 우회되지 않는가

## 8. G1 완료 게이트

모두 충족 시 G1 통과:

1. 필수 모드(Farmer's Delight, Aquaculture 2, 가구 1종, TaCZ+LR)에 대해 **통과 또는 대체안이 확정**됨
2. 2클라이언트 + 전용 서버에서 접속·전투·요리·낚시·가구 설치 정상
3. 레시피 차단·복제 방지·무한 내구도가 모든 모드에서 구현 가능함을 확인
4. locklist(해시 포함)와 롤백 절차 확정
5. 미해결 위험이 위험 등록부에 책임자·기한과 함께 기록됨
