# G5 — UX·와이어프레임 v0.1

> 대상: 명세서 3.3장(UI), 4장(최초 접속), 6장(강화·도감·칭호), 7.3장(상점), 8장(게시판), 9장(주택·가구 뽑기), 12장·19장(관리자). 로드맵의 G5 단계.
> 연관: `asset-requirements.md`(UI 요구·에셋), `starter-weapon-spec.md`, `cosmetics-social-spec.md`, `gearbridge-spec.md`, `special-effects-spec.md`.
> 상태: **[제안]**. 와이어프레임은 구조와 정보 배치를 보여주는 **저충실도 스케치**이며 시각 디자인(색·아이콘·폰트)은 아니다. 한글 폭 때문에 모노스페이스 정렬은 근사치이고, 오른쪽 테두리는 생략했다.
> **2부 `g5-wireframes-2.md`:** 직업(W-70~75), 공통(W-80~88), 보스·콘텐츠(W-100~116), 관리자 세부(W-91~96)를 이어서 정리했다.
> 표기: `[버튼]` 버튼, `( )`/`(●)` 라디오, `[✓]`/`[ ]` 체크, `▓▓░░` 진행 막대, `🔒` 잠금(이모지는 설명용이고 실제 UI는 아이콘).

## 0. 공통 원칙

### 0.1 서버 권위

- 화면의 모든 수치·확률·가격·횟수는 **서버가 내려준 값**을 표시한다. 클라이언트는 `요청`만 보낸다(명세 3.3장).
- 모든 결과 확정 요청은 `request_id`를 포함한다(중복 클릭 방지, 멱등성). 응답 대기 중 버튼은 비활성 + 스피너.
- UI를 닫거나 접속이 끊겨도 서버 상태가 정본이므로 재접속 시 이어서 복원한다.

### 0.2 레이아웃 기준

- **논리 해상도 기준 480×270**(GUI 배율 2~4에서 모두 읽히도록). 최소 지원 배율은 2.
- 안전 영역: 가장자리 8px 여백. 큰 화면 패널은 가운데 정렬.
- **공통 프레임:** 좌측 탭 레일(아이콘+텍스트) + 상단 제목줄(화면 이름, 재화, 닫기) + 본문 + 하단 도움말줄.

```text
 ┌──────────────────────────────────────────────────────────────
 │ [아이콘] 화면 이름                         ◈ 12,340 Coin   [X]
 ├────────┬─────────────────────────────────────────────────────
 │ 내 정보 │
 │ 직업    │                    본문 영역
 │ 강화    │
 │ 도감    │
 │ 상점    │
 │ 거래    │
 │ 주택    │
 │ 칭호    │
 │ 가이드  │
 │ 워프    │
 ├────────┴─────────────────────────────────────────────────────
 │ [?] 도움말: 선택한 항목에 대한 한 줄 안내          ESC 닫기
```

### 0.3 공통 컴포넌트

| 컴포넌트 | 용도 |
|---|---|
| 탭 레일 | 메인 메뉴 이동(키보드 ↑↓, 숫자 1~0) |
| 재화 표시 | Coin, 강화석 등 현재 보유량(서버 값) |
| 확인 팝업 | 되돌릴 수 없는 행동 전 확인(비용·확률·경고 포함) |
| 토스트 | 결과 알림(성공/실패/에러), 3초 |
| 진행 막대 | 도감률, 직업 경험치, 천장 카운트 |
| 카드 그리드 | 무기 선택, 도감, 가구 목록 |
| 툴팁 | 항목 상세(등급 색 + 텍스트 병기) |
| 확률표 | 강화·뽑기 확률 공개 표(버전 표시) |
| 빈 상태/에러 상태 | 아무것도 없을 때, 서버 오류·권한 없음·점검 |

### 0.4 접근성·입력

- 색에만 의존하지 않는다(등급·상태는 색 + 아이콘 + 텍스트).
- 키보드만으로 모든 화면을 조작(탭 이동, Enter 확정, ESC 닫기). 마우스 우클릭/휠 의존 금지.
- 텍스트 크기 3단계, 이펙트 상세도 옵션(`fx-spec.md`), 모션 감소 옵션(화면 흔들림·번쩍임 끔).
- 모든 문자열은 번역 키(ko/en)로 관리한다.

### 0.5 우선순위

| 단계 | 화면 |
|---|---|
| **P0** | 첫 접속 흐름(W-01~W-06), HUD(W-11), 메인 메뉴(W-10), 강화창(W-20) |
| **P1** | 내 정보·프로필(W-12), 진화(W-21), 도감(W-30), 칭호(W-31), 상점(W-40) |
| **P2** | 거래·의뢰 게시판(W-50), 주택·가구(W-60), 가구 뽑기(W-61), 관리자(W-90) |

## 1. 첫 접속 흐름 (W-01~W-06)

흐름: `접속 → 닉네임 → 직업 → 시작 무기 → 확정 → 지급 안내 → 필드`. 진행 단계 표시를 모든 화면 상단에 둔다. 취소(ESC)는 외부 상호작용을 제한하되 재접속 시 이어서 진행한다(명세 4.1장).

### W-01 닉네임 지정

```text
 ┌─────────────────────────────────────────────────────────
 │   ①닉네임  ─  ②직업  ─  ③시작 무기
 │
 │              서버에서 사용할 이름을 정하세요
 │
 │   닉네임   [ 나무꾼아저씨_______ ]   (2~12자)
 │            ✓ 사용할 수 있는 이름입니다
 │
 │   미리보기   [칭호 없음] 나무꾼아저씨
 │
 │   · 한글/영문/숫자/_ 사용 가능   · 운영자 사칭·욕설 불가
 │   · 이후 변경은 쿨타임과 수수료가 있을 수 있습니다
 │
 │                                    [ 다음 ]
 └─────────────────────────────────────────────────────────
```

| 항목 | 요청/응답 | 상태 |
|---|---|---|
| 입력 중 검사 | `CheckNickname(text)` → 사용 가능/중복/금칙어/길이/서식 문자 | 실시간(디바운스), 사유 텍스트 표시 |
| 확정 | `SetNickname(request_id, text)` | 실패 시 사유(중복 등), 재입력 |
| 재접속 | 서버가 미완료 단계 복원 | 이어서 표시 |

```text
 │   │ 작물을  │  │ 광물을  │  │ 요리로  │  │ 물고기를│
```

- 직업 카드 4개(농부/광부/요리사/어부), 선택 시 하단 상세(시작 도구, 수입 구조, 변경 정책).

### W-03 시작 무기 선택 (U-01)

```text
 ┌─────────────────────────────────────────────────────────
 │   ①닉네임  ─  ②직업  ─  ③시작 무기
 │
 │   ┌한손검──┐ ┌단검────┐ ┌쌍검────┐        ┌ 상세 ─────────
 │   │ [모델] │ │ [모델] │ │ [모델] │        │  [3D 회전 프리뷰]
 │   └────────┘ └────────┘ └────────┘        │
 │   ┌대검────┐ ┌창──────┐ ┌도끼────┐        │  목제 한손검
 │   │ [모델] │ │ [모델] │ │ [모델] │        │  균형 잡힌 만능 무기
 │   └────────┘ └────────┘ └────────┘        │  공격 속도 ▓▓▓▓░
 │                                            │  사거리    ▓▓▓▓░
 │   ▶선택: 한손검                              │  범위      ▓▓▓░░
 │                                            │  치명 보너스 ▓▓░░░
 │                                            │  콤보: 2연타 + 베기
 │                                            │  [ 체험하기 ] [ 선택하기 ]
 └─────────────────────────────────────────────────────────
   · 선택은 계정당 1회, 24시간 안에 1회 무료 교체 가능
```

| 요소 | 동작 |
|---|---|
| 카드 6개 | 선택 하이라이트, 키보드 ←→↑↓ 이동 |
| 상세 패널 | 3D 회전, 역할 한 줄, 스탯 막대 4개, 콤보 요약 |
| `체험하기` | 연습장으로 이동(W-04), 임시 대여 |
| `선택하기` | 확인 팝업(W-05) |
| 서버 | 후보 목록·횟수는 서버가 내려줌(`starter.json`) |

### W-04 연습장 체험 HUD (U-02)

```text
 ┌─────────────────────────────────────────────────────────
 │  [체험 중] 목제 한손검(대여)                       [선택 화면으로]
 │
 │                  ┌허수아비┐      피해  6.0
 │                  │  ┼  │      초당  9.8
 │                  └───────┘      콤보  2/2
 │
 │   (아래: 일반 HUD 쿨다운 표시)
 └─────────────────────────────────────────────────────────
```

- 허수아비 피해 수치(타당·초당)와 콤보 단계 표시. 체험 결과는 **경제·보상·랭킹에 반영되지 않는다**.
- `선택 화면으로` 버튼과 단축키. 연습장 밖으로 나가면 대여 무기 회수.


| 요소 | 규칙 |
|---|---|
| 확률표 | **서버가 선택한 `rates_version` 확률 공개**, 합 100% |
| 비용·보유 | 부족하면 `강화하기` 비활성 + 부족 항목 표시 |
| 고위험 확인 | 파괴 확률 ≥ 임계(설정)면 체크 필수 |
| 특수 효과 미리보기 | 다음 해금 단계와 효과 요약(`special-effects-spec.md` 7장) |
| 이력 | 강화 이력(`gear_history`) 최근 N건 |

**결과 연출(같은 화면 전환):**

```text
 ┌──────────── 강화 결과 ────────────
 │      ✦ 성공! +7 → +8 ✦
 │   [검 모델 + 이펙트]
 │   공격력 34.0 → 36.8
 │   새 도감 기록: 철 한손검 +8 (최초 달성)   🏅 칭호 조건 진행 2/3
 │                         [ 계속 강화 ]  [ 닫기 ]
 └─────────────────────────────────────
   (유지:  "변화 없음"   /   파괴:  "장비가 사라졌습니다 · 도감 업적은 유지됩니다")
```

- 결과는 서버 확정 **후** 표시(연출이 결과를 바꾸지 않음). 파괴 연출은 본인에게만 크게, 서버 공지 없음(`cosmetics-social-spec.md` 4.1).
- 상태: `처리 중`(버튼 잠금, 장비 잠금 `serial`), `실패(재화 부족/장비 이동됨)`, 접속 끊김 후 재접속 시 **결과 복원**(`outbox`).
